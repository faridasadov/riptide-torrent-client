Riptide help

Use Riptide to add magnet links, import .torrent files, manage download folders and control bandwidth from one local desktop app.

Adding torrents

  • Click Add torrent to paste a magnet link or choose a .torrent file.
  • Double-clicking a .torrent file in Windows opens Riptide and imports it.
  • Magnet links are supported through the registered magnet: protocol.

Download location

  • Windows builds download to Downloads\Riptide by default.
  • Change the default folder in Settings > Downloads.
  • Use Files to browse, move or delete downloaded content.

Speed and queue controls

  • Set per-torrent limits from the details pane or context menu.
  • Set global limits and active torrent limits in Settings.
  • Use pause, resume and force recheck from torrent actions.

RSS and watch folder

  • Add RSS feeds and auto-download rules from the RSS screen.
  • Enable a watch folder to auto-import .torrent files placed there.
  • Rules support wildcard matching and optional regex with re:.

Privacy and networking

  • Riptide runs locally and stores data on this machine.
  • No telemetry is sent by the app.
  • For VPN use, bind the client to the VPN interface in connection settings.

Troubleshooting

  • If downloads do not start, check tracker status, DHT and the incoming port.
  • If a folder is blocked, choose a path inside the allowed download roots.
  • Default local login is admin / admin unless changed before launch.
