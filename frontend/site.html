Why Riptide

A torrent client that respects your screen and your time.

See the whole swarm

Peers, files, trackers, speeds, ratio, and ETA stay visible without burying you in grey tables.

Readable throughput

Aquamarine means download and coral means upload across the app, charts, badges, and rows.

Storage control

Browse, move, and delete downloaded files inside the configured allowlisted download root.

Session login

The frontend uses a clean login flow while API clients can still use Basic Auth.

Self-healing service

A systemd timer can restart the backend if the health endpoint stops responding.

VPN kill-switch

nftables rules restrict the torrent service user to loopback and the configured VPN interface.

The interface

Designed like an instrument, not a spreadsheet.

Riptide puts live status, detail inspection, and download folder operations into one dense desktop-style surface.

  • Selected rows use the canonical aqua inset bar
  • Numbers use tabular mono typography
  • Accents are semantic, never decorative
